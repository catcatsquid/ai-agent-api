# 文档

本目录原有的文档与报告（项目总览、架构审查与代码阅读地图、缺陷与修复报告、
方法论、案例复盘、题库工程、面试自测清单、部署指南等 **18 个文件**）
**已移出仓库**，暂存在仓库外，不随仓库分发。

## 为什么

那批文档大部分是**用 AI 辅助整理成稿的** —— 素材来自真实的排查记录，但成稿时的
判断、措辞、归纳是否与本人一致，需要逐篇过一遍才知道。在核实完成之前，
不适合把一个"我自己还没完全背书的版本"当作这个项目的说明对外分发。

已核实的内容会逐步迁回本目录。

## 现在以什么为准

**代码与测试是唯一权威。**

- 源码注释里记录了当时的实测结论（哪次实测、什么现象、为什么这么改）
- `tests/` 下的断言是当时真实验证过的不变量
- 项目说明见仓库根目录的 [README.md](../README.md)
- 版本变更见 [CHANGELOG.md](../CHANGELOG.md)

如果发现任何文档里的说法与代码或测试不符，**以代码和测试为准**。
