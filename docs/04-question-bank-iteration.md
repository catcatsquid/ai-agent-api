# 习题库构建 - 迭代文档

## 目标

从操作系统往年试卷 PDF（回忆版）中自动提取题目，生成结构化习题库 JSON，用于复习模式和量化测试。

## 核心设计决策

1. **题目用截图，不用文本** — 回忆版试卷有大量表格、代码块、图表，纯文本提取会丢失排版和结构信息。截图保留原始视觉效果，100% 可读。
2. **答案用 LLM 生成** — 提取题目文字 + 必要时 VLM 描述图表，喂给 LLM 生成参考答案。
3. **不标 confidence** — 回忆版本来就不可能和原题一模一样，只要题目逻辑完整、知识点考察不超纲即可使用。只标 needs_review（格式异常时）。
4. **答案格式统一** — 选择题 answer 只填单字母（A/B/C/D）；综合题 answer 为 null，答案全部放在 sub_questions 数组里。

---

## v1：LLM 直接拆题

### 方案
- PyMuPDF 提取全卷文本
- VLM 整页渲染描述有图表的页面
- 合并文本 + VLM 描述 → 喂给 LLM 一次性拆分所有题目

### 结果
- 15/26 道题（选择题只提取到 9/20，综合题 6/6）
- 置信度: high=13, medium=2, low=0

### 问题
1. **选择题选项重复** — question 字段和 options 字段各放了一遍选项
2. **图表看不清** — 纯文本提取，银行家算法表格变成乱码
3. **太慢** — VLM 整页渲染 5 页，全卷耗时 30 分钟
4. **API 500 错误** — 文本太长导致 LLM 调用超时/失败
5. **confidence 标注无用** — 用户反馈不需要准确度标注

---

## v2：题目截图 + 答案分离

### 改动
- 题目直接截图（按题号定位 y 坐标 → clip 截取区域）
- 答案用提取文字 + VLM 两步法生成（先 VLM 描述图表，再纯文字调 LLM）
- 去掉 confidence，只标 difficulty
- 题干和选项不重复

### 结果
- 21/21 道选择题截图成功
- 18/21 答案生成成功
- 3 道 VLM 题全部 400 错误（图片+长文本同时发送超限）

### 问题
1. **截到下一题** — y_end 取下一题 y_start，没留间距
2. **Q0 误判** — 第6页表格数据 `0.0` 被匹配成题号 0
3. **Q10 跨页截断** — Q10 题干在第2页底部，代码续到第3页，只截了第2页
4. **综合题没提取** — 只匹配了选择题题号
5. **难度标注无用** — 用户反馈不需要难度标注
6. **VLM 400 错误** — GLM-4V-Flash 不支持图片+长文本同时发送

---

## v3：最终方案（定稿）

### 改动
1. **截图边界修复** — 下一题 y_start 减 3px 间距，不再截到下一题
2. **跨页拼接** — 如果下一题在下一页，把当前页底部 + 下一页顶部拼接为一张图
3. **Q0 误判修复** — 正则排除小数格式 `(?!\d)`，`0.4` `1.0` 不再匹配为题号
4. **综合题提取** — 按大题标题（一、二、三...）分段，综合题用 S1-S6 编号
5. **综合题编号重置** — 综合题部分从 S1 开始连续编号，不与选择题 Q1-Q20 冲突
6. **留白裁剪** — trim_whitespace 裁掉截图四周白色区域
7. **答案格式统一** — 选择题 answer 只填单字母；综合题 answer=null，答案在 sub_questions
8. **可疑标注** — needs_review 字段：选择题答案不是 A-D、综合题缺 sub_questions 时标红
9. **去掉 difficulty** — 不标难度
10. **去掉跨页标签** — 报告中不显示"跨页"标签

### 结果
- 26/26 道题全部提取（选择题 20 + 综合题 6）
- 26/26 答案生成成功
- 选择题全部返回单字母 A-D
- 综合题全部 answer=null + sub_questions
- 0 道需审查
- 耗时约 3 分钟（纯文字题 2-3 秒/题，VLM 题 8 秒/题）

## 技术要点

### 题号定位
- 正则 `^(\d+)[.．、](?!\d)` 匹配题号，排除小数格式
- 按行扫描 PyMuPDF 的 dict 结构，获取每行的 bbox 坐标
- 跳过页眉（y<60）和页脚（y>780）

### 跨页检测
- 如果下一道题的 page = 当前题 page + 1，认为当前题跨页
- 截取当前页底部 + 下一页顶部，垂直拼接为一张图

### VLM 策略
- 只对矢量绘图数 >=3 的题目做 VLM（有表格/图表的题）
- 两步法：先 VLM 描述图表 → 再纯文字调 LLM 生成答案
- 避免直接发图片+长文本给 VLM（GLM-4V-Flash 会 400）

### 答案质量检查
- 选择题：answer 必须匹配 `^[A-D]$`
- 综合题：answer 必须为 null，sub_questions 不能为空
- 不合规的标 needs_review=true，在报告中红色标注

## 使用方式

```bash
# 处理单份试卷
python -m course_agent.question_bank "data/操作系统/往年题/2024年秋...pdf"

# 批量处理所有往年题
python -m course_agent.question_bank
```

## 后续优化方向

1. **增量处理** — 只处理新试卷，已有的不重新跑
2. **答案人工校对** — 报告里标红的 needs_review 题目，人工修正后更新 JSON
3. **量化测试集** — 从习题库中筛选 confidence 高的题目作为自动评分测试集
4. **知识点标签完善** — 当前 topic 是 LLM 自动分类，可以人工审核统一
