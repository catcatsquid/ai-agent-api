# AI Agent 前端界面

## 🌟 功能特点

### 1. 现代化聊天界面
- 响应式设计，支持移动端
- 暗黑模式切换
- 流畅的动画效果
- 实时消息显示

### 2. 智能交互
- 实时流式响应
- 工具调用可视化
- 知识来源标注
- 多轮对话历史

### 3. 用户体验
- 快捷问题按钮
- 输入中动画
- 消息时间戳
- 主题偏好记忆

## 🚀 快速开始

### 方法一：使用启动脚本（推荐）
```bash
# Windows
start_demo.bat

# 双击运行 start_demo.bat 文件
```

### 方法二：手动启动
```bash
# 1. 激活虚拟环境
.venv\Scripts\activate

# 2. 启动服务
python web_app.py
```

## 📱 访问地址

- **主界面**: http://localhost:8004
- **API文档**: http://localhost:8004/agent/docs

## 🎯 使用说明

### 基础使用
1. 在输入框中输入问题
2. 点击"发送"按钮或按回车
3. 观察AI的思考和回答过程
4. 查看工具调用和知识来源

### 快捷问题
点击页面上的快捷问题按钮，快速体验：
- "解释什么是虚拟内存"
- "进程调度算法有哪些"
- "HTTP和HTTPS的区别"
- "什么是死锁？如何避免？"

### 功能按钮
- **清空对话**: 清除所有聊天记录
- **切换主题**: 在明暗主题间切换（偏好会被保存）

## 🛠️ 技术实现

### 前端技术栈
- HTML5 + CSS3 + JavaScript
- Tailwind CSS（样式框架）
- Font Awesome（图标库）
- 纯前端实现，无需额外依赖

### 后端集成
- FastAPI提供RESTful API
- 支持SSE流式响应
- WebSocket支持（可扩展实时功能）

### API接口
```
POST /api/chat
{
    "query": "用户问题",
    "thread_id": "会话ID",
    "max_steps": 8
}
```

## 🔧 自定义配置

### 修改主题颜色
在 `static/chat.html` 中修改CSS变量：
```css
:root {
    --primary-color: #your-color;
    --secondary-color: #your-secondary-color;
}
```

### 添加快捷问题
在输入框下方的快捷问题数组中添加：
```javascript
<button onclick="sendQuickQuestion('你的问题')">问题</button>
```

## 🐛 常见问题

### Q: 页面无法加载
A: 确保后端服务正在运行（端口8004）

### Q: 消息不显示
A: 检查浏览器控制台是否有错误

### Q: 如何修改样式
A: 直接编辑 `static/chat.html` 的CSS部分
